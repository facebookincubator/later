# later

`later` is a collection of asyncio batteries for writing asyncio services at
Meta (task helpers like `herd`, `Watcher` and `cancel`, `BiDirectionalEvent`
for handshake-style synchronization, and `later.unittest` test helpers).

This folder holds the `later` Python library source, its `unittest` helpers,
and its test suite under `tests/`. The open-source packaging for the library
(PyPI/GitHub published copy) lives under `public_tld/`.
